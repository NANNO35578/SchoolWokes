# install 

- put `everforest.creatortheme` into `E:\Qt\Tools\QtCreator\share\qtcreator\themes` 
- put `everforest.xml` into `E:\Qt\Tools\QtCreator\share\qtcreator\styles`

as you can see that's my Installation Path , you should find yours ,replace it
